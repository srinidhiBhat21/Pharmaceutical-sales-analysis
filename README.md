# Pharmaceutical Sales Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of pharmaceutical sales data using Python. The objective is to identify sales trends, top-performing drug categories, and monthly sales patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- KaggleHub

## Dataset
Pharmaceutical Sales Dataset – Kaggle.

## Analysis Performed
1. Calculated total sales quantities for each ATC drug category.
2. Identified drug categories with the highest total sales.
3. Compared the top three drugs in January 2015, July 2016, and September 2017.
4. Identified the drug with the highest sales in 2017.
5. Analyzed average daily sales for each drug category.
6. Examined monthly sales trends of respiratory drugs (R03).

## How to Run the Project

1. Clone or download this repository.
2. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn kagglehub
```

3. Open Jupyter Notebook:

```bash
jupyter notebook
```

4. Open `Analysing-pharmaceutical-sales-data.ipynb`.
5. Run all cells.
